## Strict enter DDD

Web `infenter_zone_v2` 从 DD 后计数 2、玩家 57 在 level 0/(4,2)，第三次 Down 到计数 3、level 7/(1,2)，enterExit 长 0.5 秒。三个 Web 实际时间为 0.1406、0.2572、0.3904 秒；查看三张整图及 [240×200 原尺寸裁图](evidence/terra-v7-motion-review/)（x=280..519、y=350..549），画面随相机进入逐渐放大，粉色玩家和蓝色块均可见。该裁图晚期顶部截断，判断同时参照完整帧。

原版 `infenter-zone-dddu-motion-v2-20261025` 的 capture 从计数 3、level 7/(1,2) 开始记录第四步 Up，随后计数 4、level 14/(3,4)，虽同为 0.5 秒，却不是第三步 Down。实际查看原版整图 frame-0007（0.136329 秒）仅用于核实动作上下文，不能与 DDD 样本配对。已有记录明确 DDD 的严格 Enter 发生在前置步骤，并无其对应原版瞬态 PNG。因此这个相邻动作的原版视觉一致性、旧进入副本和相机细节均为 **unverified**；需要同一计数、位置、方向与实际动画时间的原版帧后才能判断。此结论不外推到整个游戏。
