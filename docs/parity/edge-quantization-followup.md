# Frozen v7 edge quantization followup

Scope: only the remaining one-byte RGB residuals in the top bevel, L-corner, and lower notch of `third_puzzle`, frozen revision `e04a40c5ee352bef46cb3fb309675a32f953cd67`. This is an offline diagnostic, not approval of a one-byte tolerance. It preserves the v7 clamp fix and does not change production, tests, native processes, observers, shaders, assets, or UV geometry.

The released E1–E5 audit in `third-corner-edge-findings.md` and `evidence/third-corner-edge-audit/` is the starting evidence. In particular: native repeats are stable; literal float32 root geometry and endpoint truncation are required; sampled white texels make the prior premultiplication alternatives equivalent; the local underlay is stable; recovered-PNG substitution was already falsified as a complete fix; the exported shader is a dummy and cannot establish the native blend pipeline.

## Hypotheses specified before experiments

1. **H1 — BC3 decode precision survives into filtering.** Native walls are DXT5/BC3, whereas v7 samples eight-bit PNG texels from a GPU readback. A BC3 alpha palette can contain rational values with denominator seven; rounding to a PNG byte before bilinear filtering can move the final framebuffer across a byte threshold. Compare exact compressed-block palette values with both recovered and GPU PNG alpha at literal, unshifted sample coordinates. This hypothesis is falsified as a complete explanation if its predicted output disagrees with any otherwise fully specified edge sample; decoding block provenance and residual direction distinguish it from merely swapping the recovered PNG.
2. **H2 — bilinear subtexel weight quantization.** D3D11 and WebGL may quantize fractional texel weights differently. Compare predefined nearest/floor binary fractional weights (8, 9, 10, and 16 bits), plus literal full precision, with the same texture and underlay. No fitted offset or fitted per-pixel choice is permitted. A single fixed rule must explain the complete evaluated edge set and exact controls. Failure rejects those concrete rules, not every possible undocumented sampler implementation.
3. **H3 — blend-stage byte quantization.** Native straight-alpha GUI blending and v7 premultiplied blending can differ when products or destination terms are rounded independently before UNORM output. Compare explicit full-precision, separately rounded source/destination terms, quantized alpha, and float32 arithmetic under fixed floor/nearest output conversion. Opaque white/grey and zero-alpha controls constrain global shifts. Any rule must match residuals and controls without per-pixel correction. Failure leaves a precise need for native fragment/blend intermediate evidence.

## Results

Completed bounded offline experiments. Each released Python experiment is exactly five physical lines. The bounded results below do not establish exact parity.

E1's interrupted extraction was retained unchanged. It reads the original `sharedassets0.assets` read-only, resolves exported scene WallTiles GUIDs, selects same-name native texture objects by the smallest alpha discrepancy against that GUID's recovered PNG, and records the selected path IDs and compressed-byte hashes. The selected BC3 data are vertically flipped to image coordinates. This is alpha provenance, not proof of RGB shader precision. Tiles 7/26/34 each have 46 rational-alpha texels; tile 1 has 92. Maximum rational-versus-GPU-PNG alpha discrepancy is 5/7 byte. Both BC3 endpoint-order branches occur, so the five-step/explicit 0,255 branch must be retained.

E2 reuses all 14 literal white-edge samples from the released E2/E3/E4 audit, substitutes the rational BC3 alpha alone, and compares the actual frozen v7 static end with native. With nearest final conversion, GPU-byte alpha misses native at 5/14 points; exact rational alpha misses 4/14. At (427,318), native=247, v7=246, GPU prediction=245.9973262, rational prediction=246.1363636; both round to246. At (323,382), native=214, v7=213, rational prediction=213.2428336. At (421,382), both alpha models produce180.2352941 while native=181 and v7=180. Rational BC3 decoding alone therefore fails as a complete explanation of these residuals under the independently supported local-underlay model. It changes the expected direction at some points, but cannot authorize a texture replacement.

E3 holds the blend formula and literal geometry fixed while testing full subtexel precision and nearest/floor fractional weights at 8,9,10,16 bits, independently with GPU-byte and exact-rational alpha and floor/nearest final conversion (36 predefined trials). No rule matches all14 native samples. The best native result still misses4/14. This rejects these specific sampler rules as complete explanations; it does not establish the actual hardware's interpolation rule or allow a fitted offset.

E4 holds full-precision sample weights fixed while testing identity/floor/nearest sampled-alpha byte conversion, full arithmetic / separately floored terms / separately nearest-rounded terms / explicit float32 arithmetic, and floor/nearest final conversion, on both alpha sources (48 trials). No rule matches native: best4/14 misses. All rules preserve the observed zero-alpha93 at(428,324) and white255 at(431,321) endpoint controls. Their literal tile7 four-neighbor alpha bytes are respectively[0,0,0,0] and[255,255,255,255]. Those endpoint controls cannot discriminate the interior byte rules, and do not establish the opaque grey shader path.

A useful new discriminator: **GPU-byte alpha rounded to nearest byte before full blending reproduces all14 actual v7 bytes exactly**, as does rounding both blend terms independently to nearest. They both preserve the endpoints and both miss native7/14. Thus the retained outputs cannot distinguish these two quantization locations even within this minimal white-edge case. This is evidence for a Web-side byte-quantization equivalence class, not confirmation that either is the real shader/blend mechanism. Float32 arithmetic alone changes none of the evaluated rounded native predictions relative to full precision.

E5 independently inventories every nonexact RGB pixel in the three original half-open ROIs, using the actual native repeats and frozen v7 image: top331, L41, notch66, all maximum1byte, all stable across native static0/1/2. Full per-pixel RGB and hashes are retained. This census includes colored/bevel samples beyond the14 white-edge discriminator; no scalar-alpha model or parity approval is extrapolated to those samples.

## Bounded conclusion and missing evidence

The three proposed mechanisms have now been tested separately without production changes. Rational BC3 alpha alone, the specified subtexel rules alone, and the specified blend/alpha quantization rules alone each fail the fully specified14-point white-edge discriminator. No cause of all438 remaining ROI pixels is confirmed. No new tolerance, fitted phase, fitted offset, geometry overlap, or per-pixel correction is proposed.

The local B values remain independently measured neighboring zero-alpha framebuffer bytes, **not a capture of the hidden destination before the edge draw**. Consequently these failures reject complete explanations under that measured-underlay model; they cannot rule out a different earlier-pass destination at covered pixels. All14 remain exact white source neighbors, so they also cannot determine colored/opaque-bevel RGB decoding or multiplication precision.

The next evidence needed is an actual native draw capture for one failing sample such as (427,318) or (323,382): bound BC3 resource/subresource, viewport and interpolated UV, sampled RGBA, post-tint/post-clamp fragment output, destination RGBA immediately before that draw, render-target format, blend factors and output byte. Equivalent Web intermediates would distinguish sampled-alpha quantization from separately rounded terms. For the top/colored/bevel residuals, the corresponding actual draw identity and preblend destination plus decoded RGB palette are needed before applying the white-alpha model. The exported dummy shader and final PNG alone do not supply these values. Such a capture is outside this offline scope; none was attempted.
