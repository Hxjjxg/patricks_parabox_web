## Status and evidence contract

- `passed` applies only to the explicitly named bounded finding with retained supporting evidence. It never means that the containing level, family, or milestone passed.
- `unverified` means that native matching action, actual Web output, measured phase comparison, independent image review, or current-source confirmation is incomplete. A capture being present is not approval.
- Keep action identity: level, setup, count, position/outer level, direction, ownership/flip and accepted mechanic. Match actual animation times, with native bracketing frames when necessary. Do not pair adjacent actions just because both last 0.5 seconds, infer timing from nominal filenames, fit offsets, resample, or relax established tolerances.
- Natural Web captures use the real controller and requestAnimationFrame loop; synthetic DOM keys are not physical keyboard delivery. Controlled native-delta replays answer discrete controller/geometry questions and cannot approve natural browser cadence. Settled snapshots cannot approve transient copies or camera motion.
- Native screenshot capture performs readback, PNG encoding and file writes. Its update delta includes observer overhead; it is not native CPU, allocation or render-count profiling. Existing instrumentation has no native Profiler/Stopwatch/GC-allocation/draw-count profile.
