# 自递归无限出口：program 缓存独立视觉复核

复核日期 2026-11-02。对象是 `visual-v1` 的 800×600、DPR 约 1 的 20 张实际 Canvas PNG；已逐张查看全部 10 组 before/after 整图。`trace.json` 描述每对在同一固定场景同步提交旧 program 与缓存 program，期间不推进动画、粒子或眼睛时钟。独立重新计算 `sha256.json` 中全部 21 文件哈希，均匹配；每组 before/after PNG 文件字节也完全相同。采集记录称每组 1,920,000 个 RGBA 字节零差异。捕获的 `wallRendering.ts` SHA256 为 `3547e22812ebbdff6e8b56a3204b2a4f411bbb3c322c3268e1f3fdbf799d62ba`，复核时工作树文件哈希与之相同。

## 自引用箱被推出边界

关卡 `infexit_ref_first`，依次输入 `DLLDRRRR`，计数 8，玩家在 level 0 的 `(5,1)`，自引用箱在 `(6,1)`；再 Right，计数 9、玩家到 `(6,1)`，箱到 `(2,4)`。原版 `original/infexit-proven-crossing-20261025` 的起止状态与这一动作匹配，原版和 Web 均为 800×600，玩家 NORMAL 动画长度均 0.5 秒。以下使用真实动画时间，而非 PNG 名义比例：

| 修复后 Web 图与时间 | 原版夹帧及时间（秒） |
| --- | --- |
| `push-motion-0.25-after.png`，0.129100 | frame-0005 0.110822；0006 0.129289 |
| `push-motion-0.5-after.png`，0.262200 | frame-0012 0.261964；0013 0.281752 |
| `push-motion-0.75-after.png`，0.378900 | frame-0017 0.372584；0018 0.395186 |

三个 Web 帧均看见右下粉色玩家旁的橙色旧位置递归副本，露出宽度随动作减小并受棋盘右边界裁切；左上无限符号旁的橙色递归副本也可见。原版六张夹帧对应内容可见，呈相同的缩进与移动趋势。没有在这些取样中看到先前出现的右下副本缺失；这不是完整递归树或像素级原版一致性的证明。Web 中间帧玩家处于闭眼状态，原版相邻帧睁眼；眼睛和粒子有独立时钟，原版还有左侧教程文字，不能仅凭这些截图归因于 program 缓存。

## 玩家自行出界

第二路线为 `DLLDRRRRURR`。最后 Right 前计数 10、玩家在 `(6,2)`；其后计数 11，玩家到 level 0 `(2,4)`，ENTER_EXIT 长 0.5 秒。三个 after 图的真实动画时间分别是 0.1266、0.2599、0.3765 秒。左上符号旁的粉色玩家副本逐渐变大，右侧旧位置粉色形象逐渐越过裁切边界，右下橙色自引用箱及其内小图像仍可见。边界、三个动作阶段和落定的五组 before/after 均相同，未见缓存引入可观察的画面缺失。没有同一动作和状态的原版图，因此这一分支的原版视觉一致性未验证。

## 范围

本复核是固定场景图像比较，不是流畅度测量或连续动画录屏；截图方法本身会扰动帧时间。它支持所采 10 个状态中 program 共享没有改变 Canvas 结果，并在可匹配原版的三个推箱时刻排除了明显旧副本缺失。不能由此推断其他视口、后端、关卡、未采样时刻或整个游戏的视觉与性能均已通过。没有操作共享浏览器页面，也没有修改生产代码。
